# 20-security.md

- APIキー・秘密鍵・アクセストークン・パスワードの実値をコード・Markdown・コミットに書かない。
- 認証（誰であるか）と認可（何ができるか）の仕組みを分離して設計する。
- サーバー専用の秘密鍵・トークンをクライアント側コードへ渡さない。
- 外部からの入力（ユーザー入力・外部API応答）は信頼せず検証する。
- 本番反映・データ削除・スキーマ移行を伴う変更は、実行前に影響範囲とrollback手段を確認し、明示的な指示がない限り実行しない。
- このプロジェクトのGit操作は専用アカウント `0-isk-0` ・専用SSH鍵のみを使う。他プロジェクトの認証情報を混在させない（詳細: `docs/SECURITY.md`）。
- このリポジトリは公開前提。他プロジェクトの固有名・他アカウント名・私的情報をコミット対象ファイルに書かない。
