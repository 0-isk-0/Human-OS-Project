# GLOSSARY.md

用語の定義。単なる作業進捗は書かない。

## Human OS

人間の思考・記憶・判断・行動を支援するOS（Operating System）。本プロジェクトが目指す最終的なシステムの呼称。

## Second Brain（外部脳）

人間の記憶・知識を外部化して管理する既存の概念（PKMツール等）。Human OSはこれをさらに発展させ、「思考そのものを支援するOS」を目指す点で区別される。

## いしこ

本プロジェクトの開発者・設計責任者。

## AI活用推進助成プログラム

千葉工業大学が実施する、Claude利用料をAIトークンとして助成するプログラム。Human OS Projectが採択されている（詳細は `docs/ROADMAP.md`）。
