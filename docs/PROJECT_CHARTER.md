# PROJECT_CHARTER.md

## 目的

Human OS Project は、「人間の思考・記憶・判断・行動を支援するOS（Operating System）」を目指す研究・開発プロジェクトである。
単なるタスク管理アプリやメモアプリではなく、人間の脳内で行われている思考を構造化し、AIと協力しながら整理・可視化・実行できる新しい情報基盤を目標とする。
最終的には、人が「考えること」に集中できるよう、記憶・タスク・知識・感情・目標・行動を一元管理するシステムを構築する。

## 背景

開発者（いしこ）は以下の課題意識を持っている。

- 頭の中で大量の情報を同時に考えてしまう
- アイデアやタスクが散らばりやすい
- 情報を整理したい欲求が非常に強い
- AIを「検索ツール」ではなく「共同開発者」として活用したい

この「脳内を整理するOS」という発想から Human OS Project が生まれた。

## AIとの役割分担

AIには以下を積極的に期待する。

- 提案・改善案・設計レビュー
- 実装・技術選定
- 問題発見・ドキュメント整備

一方でAIに求める姿勢:

- 事実と推測を区別すること
- 根拠を示すこと
- 思い込みで仕様を変更しないこと
- 設計思想を尊重すること

仕様・目的・設計思想など重要な意思決定は開発者自身が行う。

## 最終ビジョン

AIと人間が共同で思考し、人間の知的生産性を飛躍的に向上させる「思考OS」を構築すること。将来的には長期記憶・思考履歴・プロジェクト管理・学習管理・タスク管理・人間関係管理・AIエージェント連携・外部サービス連携・自動化を統合し、「人生全体を支援するOS」へ発展させることを構想している（詳細は [`docs/ROADMAP.md`](ROADMAP.md)）。
