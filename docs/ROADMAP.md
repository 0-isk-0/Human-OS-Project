## 段階（現時点の想定・未確定）

### Phase 0: 基盤構築（現在地）

- Gitリポジトリ・Claude Code運用ルール（本テンプレート）の整備
- `0-isk-0` アカウントでの分離運用の確立
- 完了条件: このドキュメント構成がリポジトリにpush済みであること

### Phase 0: 本人ケーススタディ（コードなし・Claude Enterprise内で完結）

- 第1回セッションは原点レポート（ローカル保管）の暫定モデルの検証から始める
- インタビュー手順・人格モデルスキーマを、本人への適用を通して磨く
- 完了条件: 全ドメインにconfirmed仮説が揃い、「自分の説明書」を通読して本人が「これは自分だ」と感じられること
- 副産物: APIキー申請の「進捗と正当な理由」、HOS Insight（一般化可能な知見）

### Phase 1: 友人ミニテスト（1〜2人・コードなし）

- 本人以外でも方法が機能するかを最小コストで確認する（同意手順・所要時間・誤推定パターン・理解実感）
- Claude上で手動実施。Webアプリより先に行うことで、作るべきものを誤らない
- 完了条件: 本人以外の1人以上が「理解が深まった」と感じ、誤推定パターンが記録されている

### Phase 2: Webアプリ MVP

- チャット（AIインタビュアー）＋人格モデル可視化の2画面構成
- 前提: Claude APIキーの入手（大学申請 or 自費）。Phase 0〜1の実績を添えて申請する
- 完了条件: ブラウザだけでPhase 0と同等のインタビュー→判定→モデル更新のサイクルが回ること

### Phase 3: 拡大検証と判断支援

- 友人3〜5人→10〜20人へのテスト拡大（アプリ上で）、共通構造と個人差の分類
- 育ったモデルを使った判断支援、成果発表用まとめ

補足: 開発者には並行する他案件があり、本プロジェクトはそれを妨げない時間配分で進める（1回の対話ごとに、本人モデルの更新とHuman OSへ一般化できる知見の両方を残す運用）。

詳細: `docs/plans/2026-07-31-initial-direction.md`（承認済み方針）＋原点レポート（ローカル保管・非公開）
