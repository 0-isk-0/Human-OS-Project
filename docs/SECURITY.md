## Git / GitHubアカウントの分離

- このプロジェクトのGit操作は `0-isk-0` アカウント・専用SSH鍵（`~/.ssh/id_github_isk`）のみを使用する。
- 開発者の他のプロジェクト・アカウントの認証情報・鍵をこのリポジトリの操作に使わない。
- このリポジトリは公開される前提で書く: 他プロジェクトの固有名・他アカウント名・私的情報をコミット対象ファイルに書かない。インタビューログ・人格モデルなどの私的データの置き場所は、公開リポジトリの外とする（場所は `[要確認]`）。
