# 対話アルゴリズム v0.2（インタビュー手順書）

ステータス: ドラフト（v0.2）。原点レポート（ローカル保管・非公開）の対話サイクル・セッションフォーマットを統合した。Phase 0でいしこに適用しながら改訂する。

## 目的

1回45〜60分程度のセッションを繰り返し、`personality-model-v0.md` のスキーマに沿って仮説を提示・判定・更新する。

## 中心サイクル（すべての対話の基本形）

1. 具体的な質問・出来事・感情を入力してもらう
2. AIが**事実と推測を分けて**仮説を提示する（根拠・確信度・確認したい点つき）
3. 本人が「合う・違う・一部だけ合う（＋言い直し）」を返す
4. AIがモデルと確信度を更新する
5. 新しい矛盾や不足を確かめる問いを出す

**AIの仮説が外れて本人に直されることは失敗ではなく、モデルを高精度化する主要データである。**

## 全体ルール

- **誘導しない**: クリーンランゲージの原則（本人の言葉だけを質問に埋め込む）。
- **事実と推測を分離**: 仮説は必ず `unconfirmed` として提示し、本人判定を経る。
- **瞬間反応と最終判断を分ける**: 「最初にどう感じたか」と「最終的にどうするか」を同じ質問で聞かない。反応→内的処理→外部確認→最終判断を分けて記録する。
- **反証を隠さない**: 仮説に合わない回答が出たら、条件差（いつ合って、いつ合わないか）を確かめる質問に変換する。
- **断定しない**: 「あなたはこういう人」ではなく「この事実から、こういう仮説が立つ。確信度は◯」。
- **記録**: 発言ログにIDを振り、仮説の `evidence` / `counter_evidence` から参照できるようにする。
- **1セッション1テーマ**: 安心、信頼、成功、努力、孤独、才能など、1回につき一つ。

## セッション構成

### 0. チェックイン（5分）

- 今日の調子から入り、environmentドメインのデータを自然に1件取る
- open_questionsから今日のテーマを選ぶ

### 1. 素材出し（10分）

テーマに応じて具体的なエピソードを3つ程度出してもらう。抽象論ではなく実際の出来事・選択・行動を聞く（3〜8問）。

### 2. 掘り下げ（20〜30分）— 手法の使い分け

| 状況 | 手法 | 問いの型 |
|---|---|---|
| 要素が3つ以上ある | レパートリーグリッド | 「この2つは似ていて、これだけ違う。何が違う？」→ 本人固有の評価軸を抽出 |
| 大事なこと・好き嫌いが出た | ラダリング | 「それはなぜ重要？」を終端まで反復（尋問にならないよう言い換える） |
| 比喩・イメージが出た | クリーンランゲージ | 「その『◯◯』は、どんな『◯◯』？」 |
| 感情的な出来事が出た | 反応/処理の分離 | 「最初の瞬間は何を感じた？」→「そのあと、どうした？」を別々に聞く |
| やりたいこと・行動の話 | GROW | 目標→現状→選択肢→意思。goalsドメインの3層に対応づける |
| 矛盾・両価性が見えた | 動機づけ面接 | 矛盾を指摘せず両面を要約して返す。条件差を確かめる |

### 3. 仮説提示と判定（10分）

- セッション中の発言から仮説を提示（ドメイン・根拠・確信度つき、`unconfirmed`）
- 本人が1件ずつ「合う／違う／一部合う」で判定。「一部合う」は本人の言葉で言い直してもらう（`restatement`）
- **この判定体験こそがプロダクトの核**。雑にしない

### 4. クローズ（5分）

セッション記録として次を残す：

- 今回のテーマ / 本人の回答 / 確認できた事実
- 新しい仮説・根拠・本人による修正・モデルの変更点
- 未検証の問い（open_questions）
- 実生活で試せる小さな行動（行動実験）
- 一般化できる示唆（HOS Insight候補）

## Phase 0 セッション計画

**第1回: 原点レポートの検証**。既存の暫定モデル（原点レポート内、確信度つき）を1件ずつ仮説として提示し直し、本人が「合う／違う／一部合う」を判定する。本人自身が「微妙に合っている気も違う気もする」と感じているため、これをそのまま最初の検証対象にする。

第2回以降: 判定の結果生まれたopen_questionsと、原点レポート「次に深めるべきテーマ」リスト（ローカル保管）から選ぶ。

Phase 0の完了条件: 全ドメインにconfirmed仮説が揃い、生成した「自分の説明書」を通読して本人が「これは自分だ」と感じられること。

## 実行方法とデータの置き場所

コードは書かず、Claude上でこの手順書を読み込ませて実行する。セッションログとモデル（個人データ）は `.local/model/`（Git管理外）に保存する。リポジトリにコミットするのは手順の改訂と、個人情報を除去したHOS Insightのみ。
