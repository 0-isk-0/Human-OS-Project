# 科学的制約 — 何を主張してよく、何を主張してはいけないか

ステータス: 調査完了（2026-08-01）。**本ドキュメントは方針より上位の制約**として扱う。ここに反する機能・文言は実装しない。

## 1. 結論: 「生育環境が性格を作った」は主張できない

| 知見 | 内容 | 確度 |
|---|---|---|
| 共有環境の寄与はほぼゼロ | Polderman et al. (2015) Nature Genetics。1,458万双生児ペア・17,804形質のメタ解析。全形質平均の遺伝率49%。**69%の形質が「加算的遺伝のみ」モデルと整合し、共有環境の実質的寄与の証拠を欠く** | 🟢 |
| 非共有環境も特定できていない | Turkheimer & Waldron (2000): 測定された非共有環境変数が説明する分散は**1〜3%**。Plomin (2024): 親の環境測定は21歳時の行動問題の非共有環境分散の**0.2%**しか予測しない。結論は「非共有環境は**実在するが本質的にランダム**」（内因性の発達ノイズ） | 🟢 |
| 出生順の性格への効果はほぼゼロ | Rohrer et al. (2015) PNAS, N>20,000。Big Fiveへの効果なし | 🟢 |
| 回顧的報告は過去の記録として使えない | Baldwin et al. (2019) JAMA Psychiatry, 16研究25,471名。前向き記録と回顧報告の一致は **κ=0.19**（ほぼ偶然一致）。記録がある人の52%が報告せず、報告した人の56%に記録がない | 🟢 |
| 「環境」の測定自体が遺伝的 | Plomin & Bergeman (1991)「The nature of nurture」。家族環境尺度・ライフイベント尺度に実質的な遺伝成分。**本人が報告する「育った環境」は、それ自体が部分的に本人の表現型** | 🟢 |
| 因果の矢印が逆でありうる | 誘発的遺伝環境相関。「厳しく育てられた→反抗的」ではなく「気質→厳しい養育を誘発した」が同等以上に妥当 | 🟢 |

### ⚠️ 重要な訂正 — 「共有環境≈0」を強く言いすぎてはいけない

追加調査の結果、上記の制約は**一方向に強すぎた**ことが判明した。反対方向への過剰主張（「育ちは関係ない」）も同様に支持されない。

| 訂正すべき点 | 内容 | 確度 |
|---|---|---|
| **Turkheimer 自身の留保** | 三法則を定式化した本人が同じ論文で、遺伝優位に見えるのは「**実質的というより方法論的（more methodological than substantive）**」な理由によると明記。「双生児法は有用な方法論的近道だが、**遺伝子が環境より根源的であることを示すものではない**」 | 🟢 |
| **遺伝率はデザインで倍以上変わる** | 双生児法 **.47** / 家族・養子法 **.22** / SNP遺伝率 **.00〜.21**（Big Five）。デザインだけで異質性の80%を説明する（Vukasović & Bratko 2015, Psychological Bulletin, N=113,452） | 🟢 |
| **養子研究には範囲制限がある** | 養親家庭は審査を通っており環境分布の上半分に限定。制限は約67%。補正すると**共有環境はIQ分散の最大50%を説明しうる**（Stoolmiller 1999）。→ 「養子きょうだいの相関ゼロ」は「**まともな家庭どうしを比べればゼロ**」の意味 | 🟢 |
| **アウトカムによっては共有環境は非ゼロ** | 児童期IQ **c²=.33**（Haworth et al. 2010）／規則違反行動 **c²=.18**、攻撃性は最小（Burt 2009）／反社会的行動全般 **c²=.16**（Rhee & Waldman 2002, 51研究） | 🟢 |
| **遺伝率の一部は「環境を呼び込む経路」** | 誘発的・能動的rGE により、遺伝率には「遺伝的傾向が環境を引き寄せて効く分」が含まれる。**この経路は環境側から遮断しうる**ため、遺伝率の高さから「介入不可能」は導けない | ⚪ |
| **測定モダリティで変わる** | 自己報告 h²=.42–.56 に対し他者評定 h²=.57–.81（Riemann et al. 1997）。「共有環境≈0」がとりわけ**自己報告パーソナリティ尺度**で強く出る事実自体、測定のアーティファクトの可能性を排除できていない | 🟢 |

**正しい言い方**:

> 「共有環境≈0」は「**研究されてきた環境の範囲の中では**、家庭間の差が成人の自己報告パーソナリティの個人差をほとんど説明しない」という意味。**検出限界であって、不在の証明ではない。**

**したがって、本プロジェクトが言ってよいこと／言ってはいけないことは、両方向にある**:

| ✗ 言ってはいけない | 理由 |
|---|---|
| 「あなたの育ちが今の性格を作った」 | 個人差の説明力は小さい |
| **「育ちは性格に関係ない」** | **反対方向の過剰主張。範囲制限・アウトカム依存・Turkheimer本人の留保に反する** |
| 「遺伝率が高いから変えられない」 | rGE 経路は環境側から遮断しうる |

## 2. では何が主張できるのか

### 2-0. 一行でまとめると

> **子ども時代の環境が確実に予測するのは、(a) 家族が手渡す文化的「内容」**（宗教、政治的ラベル、言語、味の好み、学歴の水準）**と、(b) 剥奪が閾値を超えた場合の損傷であって、能力・性格・自己観といった「器」の個人差ではない。**

**これを一つの例が完璧に示している**🟢（TEDS 5,390双生児ペア ほか）:

| 何を測るか | 遺伝 h² | 共有環境 c² |
|---|---|---|
| **食物新奇恐怖**（新しいものを食べたがらない性格） | **.78** | **0（検出されず）** |
| **何を美味しいと思うか**（デザート・果物・野菜の嗜好） | .20〜.51 | **強い（.5〜.6程度）** |

→ **同じ「食」でも、性格は遺伝、内容は家庭。これが本プロジェクトの設計方針そのものである。**

### 2-0-1. 因果主張の可否 — 効果量つき判定表

| 領域 | 効果量 | 判定 |
|---|---|---|
| 虐待 → 愛着無秩序 | **d = 2.19** | 🟢 **主張可（大）** |
| 家庭 → 宗教性・宗派 | **c² = .46〜.56**、**養親子相関 .55〜.60**（遺伝的に無関係なのに） | 🟢 **主張可（大）**。行動遺伝学で最もクリーンな環境伝達の証拠 |
| 家庭 → 学歴 | **c² > 1/3**。ポリジェニックスコアの直接効果は家族内統制で**約半分に減る** | 🟢 **主張可** |
| 家庭 → 特定の食物嗜好 | c² ≈ .5〜.6 | 🟢 **主張可** |
| 近隣の質 → 成人所得 | **曝露1年あたり約4%改善**（700万世帯超の郡間移動分析） | 🟢 **主張可** |
| 現金給付 → 行為障害症状 | 脱貧困群の症状が**非貧困群の水準まで正常化**（カジノ利益分配の自然実験、N=1,420）。**効果は行為障害・反抗挑戦性障害に特異的で、不安・抑うつには効果なし** | 🟢 **主張可（貧困層限定・外在化問題に選択的）** |
| 養育環境 → 成人IQ | **+3〜4点**（0.2〜0.3 SD、スウェーデン養子きょうだい設計） | 🟢 主張可だが**小** |
| 育児介入 → 感受性 / 愛着安定 | d = 0.33 / **0.20**（RCT 70研究） | 🟢 主張可だが**小** |
| 親の感受性 → 乳児愛着 | **r = .24**（66研究 N=4,176） | 🟢 だが小（分散の6%） |
| 遺伝統制後のACE効果 | OR 1.52 → **1.20**（一卵性双生児内）。性的虐待は例外的に頑健（OR=1.80） | 🟢 **2〜3割減衰するが残る** |
| **ACE数 → 個人の転帰予測** | **AUC 0.57〜0.63**（0.50=偶然） | 🔴 **個人予測としては否定**。集団の用量反応は真だが、**スコアで個人を選別する介入は効果を持たない可能性が高い** |
| 乳児愛着 → 成人の愛着スタイル | r ≈ .17〜.28。**15年超の間隔では有意でなくなる** | 🔴 **素朴な形では否定** |
| **育て方 → 成人の自尊心** | **c² ≈ 0**（成人双生児3,756ペアほかで一貫） | 🔴 **否定** |
| 育て方 → 成人パーソナリティ | c² ≈ 0（全17,804形質の69%が純加法遺伝モデルと整合） | 🔴 **否定** |
| 育て方 → 成人IQ | c² ≈ .10（Wilson効果: 18〜20歳で h²≈.80 に漸近） | 🔴 **ほぼ否定** |

**⚠️ 愛着の行動遺伝学は発達段階で結論が反転する**🟢: 乳児期の愛着は**環境的**（h²≈0, c²有意）だが、青年期（h²≈.40）・成人期（h²≈.36, c²≈0）では遺伝的になり共有環境の寄与が消える。「乳児期の環境的個人差が成人愛着に持ち越される」経路は行動遺伝学的に見えていない。

**⚠️ 価値観の伝達には測定上の罠がある**🟢: 子が親の価値を正しく知覚する精度は r≈.47〜.49 だが、**青年を無関係な大人とランダムにペアにしても r≈.33〜.38 出る**（共通の文化的ステレオタイプだけで）。**家族固有の真の信号は実質 r≈.10〜.16 分にすぎない。**

### 2-1. 環境が確かに効く領域

| 領域 | 効果 | 確度 |
|---|---|---|
| **深刻な逆境 → メンタルヘルス** | 準実験デザイン（双生児不一致法等）のメタ解析で調整後 **d=0.31**（未調整0.56、**調整で45%縮小**＝見かけの関連の約半分は交絡）。原著者は「小さな因果的寄与」と表現 | 🟢 |
| **親の環境づくり → 学歴達成** | Kong et al. (2018) Science。親の**非伝達**アレルのポリジェニックスコア効果が伝達アレルの**29.9%**。遺伝的養育（genetic nurture）の直接証明 | 🟢 |
| **宗教性・宗派所属** | 共有環境の寄与が実質的（所属宗派はほぼ完全に家庭伝達） | 🟡 |
| **政治的態度** | 青年期に共有環境が実質的、成人期に減衰 | 🟡 |
| **価値観の内容** | 親子の実際の価値観一致 r≈.15–.30 | 🟡 |
| **言語・具体的スキル・食嗜好** | ほぼ完全に環境 | ⚪自明 |

**読み取れるパターン** ⚪: 環境が強く効くのは「**内容**（何を信じるか、何ができるか、何に所属するか）」であり、「**スタイル**（どう反応するか＝性格特性）」ではない。

### 2-2. 主観的経験の逆転（最重要）

- Baldwin et al. (2019) 🟢: 回顧報告と前向き記録は「**largely different groups**を同定しており、互換的に使えない」
- Danese & Widom (2020) 🟡: **精神病理との関連は、客観的記録より主観的経験の方が強い**

⚪ **含意**: 回顧報告は「過去の測定」としては失格だが、「**現在の主観的経験の測定**」としては有効であり、しかもそれこそが心理的アウトカムをよく予測する。**最大の方法論的弱点を設計思想に転換できる。**

### 2-3. 変化可能性

| 知見 | 内容 | 確度 |
|---|---|---|
| 成熟の原理 | 加齢で協調性・誠実性↑、神経症傾向↓ | 🟡 |
| 順位安定性 | 児童期 r≈.31 → 30代 r≈.54 → 50–70代 r≈.74 | 🟡 |
| **ライフイベントの効果は驚くほど小さい** | 結婚・離婚・失業・死別いずれも性格への効果は小さいか一貫しない | 🟡 |
| **心理療法では変わる** | 神経症傾向で d≈.37、約24週間 | 🟡 |

⚪ 大きなライフイベントですら性格をほとんど変えないという事実は、**なおさら幼少期環境が性格を「作った」とは言いにくい**ことを補強する（一貫性の議論）。

## 3. 設計への転換（3つ）

| # | 転換 | 根拠 |
|---|---|---|
| 1 | **「特性の原因」→「内容の来歴」** | 価値観・信念・所属・スキルなら環境伝達を正直に語れる。性格特性では語れない |
| 2 | **「過去の事実」→「現在の語り」** | 回顧報告は現在の主観的経験の測定として有効で、それが心理的アウトカムをよく予測する |
| 3 | **「あなたに何がされたか」→「あなたと環境の相互作用」** | 誘発的rGE。選択（どんな環境を選んできたか）／誘発（どんな反応を引き出しがちか）／操作（環境をどう作り変えてきたか）。科学的に正確で、かつ主体性を回復させる |

さらに **第4の層として「現在の環境・役割・制約」** を明示的に扱う ⚪。回顧バイアスも因果推論問題も同時に回避でき、かつ**変更可能＝実用的**。

### モデルの層構成（McAdams の3層＋現在環境）

| 層 | 扱い方 |
|---|---|
| **特性層**（性格傾向） | **原因を語らない**。現在の傾向として記述するのみ。「遺伝と、特定困難な個人的要因の両方が寄与」と正直に書く |
| **内容層**（価値観・信念・所属・スキル・興味） | **ここでのみ「育ち」を語ってよい** |
| **物語層**（意味づけ） | **主戦場**。過去の事実ではなく「現在のあなたが過去をどう語るか」を扱う |
| **現在環境層**（役割・時間の使い方・一緒にいる人・制約） | 最も安全かつ実用的。変更可能 |

## 4. 文言レベルの禁止・推奨

### 禁止

| ✗ | 理由 |
|---|---|
| 「厳しい家庭で育ったため、あなたは完璧主義になりました」 | 単一因果の断定。共有環境≈0。因果の矢印が逆の可能性 |
| 「あなたの回避的な愛着スタイルは、幼少期に十分な応答を得られなかったことが原因です」 | 縦断相関 r≈.3 程度を個人の因果として断定 |
| 「長子として育ったあなたは責任感が強い傾向があります」 | Rohrer 2015 で否定 |
| 「あなたのスコアは4です。うつ病リスクが高い状態です」 | 集団統計の個人適用。かつ不安を煽る |
| 「あなたが人を信じにくいのは、あの経験のせいです」 | 内省的アクセスの不在（Nisbett & Wilson 1977）。因果の断定 |
| 「あなたの本当の性格が分かりました」 | 本質主義。バーナム効果の悪用 |
| 「幼少期に形成されたパターンなので、変えるのは困難です」 | 予後悲観の植え付け。事実にも反する |

### 推奨

| ✓ | 根拠 |
|---|---|
| 「あなたの回答からは、**現在**〈計画を立ててから動く〉傾向が強く読み取れます」 | 現在の記述に限定 |
| 「性格の個人差のうち、**育った家庭の共通環境から説明できる部分は、意外なほど小さい**ことが分かっています。ただしこれは『家庭が関係ない』という意味ではなく、**研究されてきた環境の範囲の中では、家庭間の差で個人差を説明しにくい**という意味です」 | 正直な限界開示。**両方向の過剰主張を避ける**のが要点 |
| 「価値観や信念の**内容**は、家庭から受け継がれやすいことが分かっています」 | 内容領域では共有環境が実質的 |
| 「深刻な逆境の経験は、平均すると心の健康に**小さいながら確かな**影響を残すことが、遺伝の影響を統制した研究で示されています（効果量 d≈0.31）。ただしこれは集団の平均であり、**あなた個人がどうなるかを決めるものではありません**」 | 効果量と個人適用不可を同時に明示 |
| 「ここで扱っているのは〈実際に何が起きたか〉ではなく、**〈今のあなたが、それをどう語るか〉**です」 | 回顧バイアスの設計思想化 |
| 「因果の向きは、しばしば**逆**です。環境があなたを作っただけでなく、**あなたの気質が、受け取る環境を引き寄せてきた**可能性があります」 | 誘発的rGE。他社製品にない誠実さ |
| 「〈今の環境〉— 役割、時間の使い方、一緒にいる人、制約 — は日々の振る舞いに大きく効きます。そしてここは**変えられます**」 | 変更可能性 |

## 5. 実装上の必須ガードレール

1. **効果量を必ず併記する**。「関連があります」だけでは誤解を生む
2. **「平均的には」「集団としては」を口癖にする**。個人予測を装わない
3. **誘導質問を避ける**。質問自体が記憶を形成しうる（誤情報効果）
4. **バーナム効果テストを内部で行う**。生成した記述をランダムな他ユーザーに見せて「当てはまる」と言われるなら、その記述は情報を持っていない
5. **予後悲観を生む文言を禁止する**。変化可能性を必ず添える
6. **臨床的判断を装わない**。逆境・トラウマ領域に踏み込むなら専門家受診への導線を必須にする
7. **限界の明示的開示ページを作る**。責任回避ではなく、「学問的裏付け」を掲げる製品の信頼性そのもの

## 6. 市場ポジションとしての含意

⚪ 逆説的だが、**「育ちで性格が決まるとは言えない。ただし『関係ない』とも言えない。分かっていることと分かっていないことは、こうです」と正直に線を引くこと自体が、この市場で最も差別化された誠実なポジション**になる。競合（タイプ診断系、毒親言説、出生順性格診断）は、いずれも科学的に支持されない断定の上に立っている。

**断定しないことが弱みにならない根拠**: 数値レンジによる不確実性の明示は、情報源への信頼をほぼ下げない（d=−0.03, 有意でない）。信頼を削るのは曖昧な言語的ヘッジのほう（d=−0.21）🟢（van der Bles et al. 2020, PNAS, N=5,780）。詳細は `explanation-design.md`。
